# CampusFix

CampusFix is a Smart Campus IT Support and Infrastructure Management Platform built using Python and Django.

## Project Objectives

- Allow students and lecturers to report IT-related problems.
- Enable IT technicians to manage and resolve incidents.
- Manage university IT assets.
- Schedule and track IT maintenance.
- Monitor authorized infrastructure.
- Generate reports and analytics.

## Technology Stack

- Python
- Django
- HTML
- CSS
- JavaScript
- Git and GitHub
- SQLite (development)

Currently in the initial project setup phase.
